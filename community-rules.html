세젤귀의 약속
조용한 일상의 한 조각이 안전하고 따뜻한 공간에 머물 수 있도록, 운영팀은 모든 신고에 24시간 이내 1차 처리를 약속합니다.

1. 기본 원칙

  • 실명·SNS 계정·DM·친구 기능이 없는 익명 피드입니다.
  • 만 19세 이상만 이용할 수 있습니다.
  • 다른 회원의 게시물·코멘트·마스코트를 존중해 주세요.
  • 핫뽀짝은 자연스러운 호응을 받은 글에 부여되며, 어뷰징은 자동 제외됩니다.

2. 금지 콘텐츠

다음 콘텐츠는 자동 차단되거나 신고 즉시 블라인드 됩니다.

  • 음란/선정성 — 신체 노출, 성행위 묘사, 성희롱적 표현
  • 폭력/혐오 — 폭행 장면, 자해 인증, 차별·혐오 표현
  • 스팸·광고 — 외부 링크 반복 게시, 상업 홍보
  • 개인정보 노출 — 본인/타인의 실명·전화번호·주소·계좌 등
  • 저작권 침해 — 무단 캡처/재가공 콘텐츠
  • 아동·청소년 음란물 — 즉시 영구 정지 + 관계 기관 신고

3. 자동 모더레이션

모든 게시물은 작성 시점에 자동 검수를 거칩니다.

  • 이미지: NSFW.js 기반 분류 모델이 음란성·선정성을 사전 평가합니다. 임계값 초과 시 작성이 차단됩니다.
  • 텍스트: 한국어 욕설·혐오 표현 사전을 통과하지 않는 코멘트·닉네임은 작성이 차단됩니다.
  • 자동 검수는 1차 필터입니다. 운영팀은 모든 게시물을 사후 점검하며, 신고가 접수된 콘텐츠는 우선 검토 큐로 들어갑니다.

4. 신고 처리 절차

  1. 회원이 게시물·댓글의 ⋯ 메뉴에서 신고를 접수합니다.
  2. 접수와 동시에 해당 콘텐츠는 신고자 화면에서 즉시 숨겨집니다.
  3. 신고가 누적 3건 이상이면 자동 블라인드 처리되어 모든 회원에게 노출되지 않습니다.
  4. 운영팀은 24시간 이내 1차 검토를 진행합니다.
  5. 위반이 확인되면 게시물 삭제 + 작성자에게 단계별 제재가 적용됩니다.

5. 단계별 제재

단계조치
1차경고 + 게시물 삭제
2차7일간 작성 정지
3차영구 정지 (토스 CI 단위, 재가입 불가)
중대 위반즉시 영구 정지 + 관계 기관 신고

6. 차단

특정 회원의 콘텐츠를 보고 싶지 않다면 ⋯ 메뉴 → 차단을 선택하세요. 차단된 회원의 모든 게시물·리액션은 본인 화면에서 숨겨집니다. 차단 사실은 상대에게 알려지지 않으며, 마이 → 차단 목록에서 언제든 해제할 수 있습니다.

7. 어뷰징 방지

  • 본인 게시물에는 리액션할 수 없습니다.
  • "말랑" 리액션은 1인 1일 5회로 제한됩니다.

  • 다중 계정·자동화 도구 사용이 확인되면 즉시 영구 정지됩니다.
